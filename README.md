# ChatGPT GitHub Harness Laboratory

This repository is an explicitly authorized sandbox for testing the boundaries of the ChatGPT GitHub connector.

## Scope

All connector mutations performed by the July 2026 capability audit are confined to this repository. Experimental branches, issues, pull requests, workflow runs, artifacts, comments, reactions, and test files are intentional audit evidence.

See `audits/CURRENT_GITHUB_CONNECTOR.md` for the latest baseline after the audit is complete.
